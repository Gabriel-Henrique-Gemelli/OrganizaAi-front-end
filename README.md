# 🏗️ OrganizAI — Gestão de Obra Inteligente

> Front-end institucional e interface base do projeto OrganizAI. 

O **OrganizAI** é uma plataforma SaaS (Software as a Service) voltada para empresas de construção civil. O objetivo do sistema é centralizar e automatizar a gestão de documentação técnica e o diário de obras em um único lugar, utilizando Inteligência Artificial (Claude via Amazon Bedrock) para transcrever registros, analisar arquivos e apoiar a tomada de decisão no canteiro de obras.

*Nota: Este projeto está em desenvolvimento ativo como um Trabalho de Conclusão de Curso (TCC).*

## ✨ Funcionalidades Principais (Conceito)

*   🎙️ **Diário de Obra por Voz:** Gravação no canteiro de obras com transcrição automática e correção de termos técnicos via IA.
*   📄 **Gestão de Documentos (OCR):** Leitura inteligente de plantas, relatórios e ARTs, mantendo o controle absoluto de versões.
*   🤖 **Assistente IA Dedicado:** Chatbot para responder perguntas sobre o andamento da obra com base no histórico já registrado.
*   ✅ **Checklist de Compliance:** Acompanhamento de prazos, alvarás, licenças e certificados.
